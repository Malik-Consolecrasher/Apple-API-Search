# APPLE API SEARCH APP

## Purpose

This app allows you to search for various media using a created frontend, which connects through a frontend to the Apple API

## How to use

Simply enter the of what you would like to search into the search-bar, then it will appear in the search result (as well as some metadata)

## How to install

Download all files, then run the command "npm install" on both the frontend and backend respectively, which should install all necessery node modules required for the app to run
